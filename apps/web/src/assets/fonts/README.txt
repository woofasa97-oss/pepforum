Inter and Montserrat — self-hosted font assets

These fonts reproduce the typography selected by pepforum-ca.html without
sending visitor requests to Google Fonts. Latin and Latin Extended subsets
support the English and French interfaces; other scripts use system fallbacks.

Source stylesheet downloaded 2026-10-20:
https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&family=Montserrat:wght@300;600;700;800&display=swap
Font binaries: fonts.gstatic.com
Licenses: Inter-LICENSE.txt and Montserrat-LICENSE.txt (SIL Open Font License 1.1)
Upstream license sources: https://github.com/google/fonts/tree/main/ofl/inter
and https://github.com/google/fonts/tree/main/ofl/montserrat

The four WOFF2 files contain variable fonts shared by the declared weights.
